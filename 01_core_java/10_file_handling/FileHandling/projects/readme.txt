# 🚀 Java File Handling Projects

This folder contains practical file-handling projects built using Java (IO & NIO).

---

## 2️⃣ CSV Data Processor
Reads CSV files, removes duplicate records, validates data (like emails), and exports cleaned output.

---

## 3️⃣ Automatic File Backup System
Monitors a folder and automatically creates backup copies of files with version support.

---

## 4️⃣ Secure Notes Manager
Stores encrypted notes in files with password protection and secure retrieval.

---

## 5️⃣ Large File Splitter & Merger
Splits large files into smaller chunks and merges them back to reconstruct the original file.

---

## 6️⃣ File-Based Expense Tracker
Stores daily expenses in files and generates monthly summary reports.

---

## 🧠 Concepts Covered
- FileInputStream / FileOutputStream  
- BufferedReader / BufferedWriter  
- Java NIO (Files, Path)  
- Byte Stream Processing  
- File Parsing & Report Generation  
- Exception Handling
